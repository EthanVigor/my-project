# 习惯打卡

一个无需后端的习惯打卡静态网页。完成习惯只需轻点一下，页面会记录今日完成数量、连续天数和每月打卡轨迹。

## 本地使用

直接用浏览器打开 `index.html` 即可。也可以在当前目录启动一个本地静态服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

所有数据都保存在当前浏览器的 `localStorage` 中，不会上传到服务器，也不会在不同设备或浏览器之间自动同步。清理浏览器数据会删除全部习惯和打卡历史。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个空仓库，将本目录文件提交并推送到 `main` 分支。
2. 打开仓库的 `Settings` → `Pages`。
3. 在 `Build and deployment` 中将 `Source` 设为 `Deploy from a branch`。
4. 选择 `main` 分支和 `/ (root)` 目录，然后保存。

项目全部使用相对路径，因此发布在 `https://用户名.github.io/仓库名/` 这样的子路径下也可以正常加载。`.nojekyll` 文件用于避免 GitHub Pages 对静态资源做额外处理。

## 数据规则

- 日期按浏览器本地时区计算，并在跨日后自动切换到新一天。
- 今天可以随时勾选或撤销；过去日期只能查看，不能补卡。
- 连续天数会在今天未打卡时显示截至昨天的连续记录，任意一天缺失即中断。
- 修改习惯名称会保留历史记录；删除习惯会同时清除它的全部历史打卡数据。
